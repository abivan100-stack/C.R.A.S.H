# Core engine + main SPA — correctness & logic audit

Scope read in full: `shared/constants.js`, `shared/utils.js`, `shared/engine.js`,
`intervention-model.js`, `maptiler.js`, `app.js` (1–1967, all chunks).
Cross-checked against `data/accidents.json` (10,169 records, 24 months, all inside BBOX,
`datetime` separator is a space), `backend/main.py:97-106`, `index.html:1304-1330, 1955-1995`,
`dashboard.html:374`.

No `TODO` / `FIXME` / `XXX` / `HACK` comments exist in any audited file.
Only one `console.*` remains (`app.js:1680`, a legitimate `console.error` on data-load failure).
No `==` / `!=` loose comparisons in any audited file (only a deliberate `s == null` null-check
in `shared/utils.js:30`). Every `parseInt` in the audited files passes an explicit radix.
